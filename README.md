# Automated Gmail Verification Flow

This project demonstrates how to automate the process of logging into Gmail, navigating to the spam folder, searching for a specific email, and clicking a verification link using Selenium and Python.

## 🚀 Features

- Gmail login automation (dummy credentials used)
- Navigates to the spam folder
- Searches for a verification email by subject
- Clicks the verification link inside the email
- Includes screenshot capturing for error handling
- Uses explicit waits for stable execution

## 🛠️ Tech Stack

- Python
- Selenium WebDriver
- PyAutoGUI (for keyboard simulation)
